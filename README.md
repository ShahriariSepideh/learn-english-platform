# Learn English Platform

A simple online English learning platform built with Next.js.

## Features

- Student registration and login
- Tutor registration and login
- Student dashboard
- Tutor dashboard
- Course list
- Tutor list
- Blog page
- Dark mode support

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- React Query
- Axios

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the project in your browser:

```txt
http://localhost:3000
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Backend

The frontend connects to the Django REST API backend.
Make sure the backend is running before testing login, registration, dashboards, courses, and payments.

Default backend URL:

```txt
http://localhost:8000/api
```
